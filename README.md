# HTML

All my html learning code.

## About
This repository contains HTML examples and exercises I used while learning HTML.

## Example
Below is a simple example `index.html` you can use or copy into the repo:

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width,initial-scale=1" />
  <title>My HTML Learning</title>
</head>
<body>
  <header>
    <h1>Hello, HTML!</h1>
  </header>
  <main>
    <p>This is a simple HTML example.</p>
    <a href="index.html">Open index.html</a>
  </main>
  <footer>
    <small>Repository: pankaj2022002/HTML</small>
  </footer>
</body>
</html>
```

## Files
Put your HTML files in the root or subfolders. Example filenames: `index.html`, `about.html`, `contact.html`.
